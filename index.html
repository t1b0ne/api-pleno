Sobre el Proyecto

Pleno es una aplicación web y móvil diseñada como un proyecto académico para optimizar la organización del estudio universitario y escolar.

La plataforma permite a los estudiantes centralizar sus asignaciones escolares mediante la integración con Google Classroom. Además, incorpora un agente virtual (Eve Agent) que analiza las fechas de entrega para estructurar automáticamente planes de estudio optimizados y enviar alertas en tiempo real.

Arquitectura Tecnológica

El proyecto está diseñado bajo una arquitectura de microservicios e infraestructura ligera altamente escalable:

📱 Cliente (Mobile & Web)

Construido con React Native (Expo) y Next.js para ofrecer una experiencia multiplataforma fluida y notificaciones locales.

⚡ Backend & Base de Datos

Infraestructura reactiva impulsada por Convex DB para sincronización en tiempo real y microservicios complementarios en NestJS.

🔌 Integraciones

Sincronización automatizada periódica con la API de Google Classroom mediante flujo seguro OAuth 2.0.

🔔 Notificaciones

Entrega transparente de alertas en tiempo real a dispositivos Android e iOS utilizando Expo Push Service (FCM/APNs).

Política de Privacidad y Uso de la API de Google

Al ser un proyecto de ámbito exclusivamente escolar y de demostración técnica:

  • Uso de datos de Google: Los accesos solicitados a Google Classroom son únicamente de lectura para extraer el listado de tareas pendientes y fechas límite.
  • Almacenamiento: No compartimos, vendemos ni distribuimos información personal de los usuarios con terceros.
  • Seguridad: La autenticación se maneja mediante tokens de acceso temporal (OAuth 2.0), almacenados de forma encriptada.
